# Vite et Gourmand

Application commande en ligne de repas sur la région de Bordeaux. Mise en avant des visuels des différents menus et la possibilité de passer commande via l'application

## Fonctionnalités principales

- **Affichage responsive :** Adaptation automatique sur ordinateur, tablette et mobile.
- **Système de navigation dynamique :** Inclusion modulaire des éléments communs (`header`, `footer`) via PHP.
- **Formulaire de connexion et commande :** Validation des données côté serveur et protection contre les failles courantes (XSS, injections SQL).
- **Roles des utilisateurs :** [Ex: User, Employé et Administrateur].

---

## Technologies utilisées

- **Front-end :** HTML5, CSS3, [Bootstrap 5](https://getbootstrap.com/), JavaScript
- **Back-end :** PHP 8.x
- **Base de données :** MySQL / MariaDB
- **Outils :** Git, GitHub, [VS Code]
